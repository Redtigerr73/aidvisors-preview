# AIdvisors — prévisualisation (POC démo)

Démo statique d'un conseil consultatif IA qui débat en direct : **personnages fictifs, réponses simulées par un programme, aucun appel réseau, aucune clé API**. Ceci n'est pas un conseil juridique, fiscal ou financier.

Les sièges inspirés de personnes publiques (Warren Buffo, Stève Jobard, Charlie Mangeur, Paul Grammont, Seth Goodwin) sont des personnages fictifs : aucune affiliation ni approbation ; leurs propos sont générés, jamais des citations.

Source et documentation : dépôt privé Startlab (`research/aidvisors/demo/`). Ce dépôt n'est déployé que par `.github/workflows/pages.yml` (tests puis déploiement) ; site non indexé.
